# 微积分（甲）Ⅰ - 毕惟红

<p class="course-meta">大一上（秋冬） · 5.0 学分</p>

## 课程体验

对一个数学不是很好的同学来说，微积分和线代双开的第一学期还是有点痛苦了。

我的微积分 I 是 bwh 老师的班。老师思维很跳脱，连上三节课的体验就是越讲越快，越听越迷离，很难跟上。课前认真预习会好一些，但是认真预习本身对我而言落实起来有点艰难。

不过毕老师非常负责，每周课程结束都会给出很详细的笔记资料，供我狠狠补天用。上课听不懂的话，课后就要把笔记啃一遍。

## 经验分享

### 1. B站资源

微甲 I 我在 B 站看了大量苏德矿老师的课程来预习或补习，并同步手写笔记。

开学前几周感觉逐渐听天书、跟不上进度后，我开始靠看网课来补习。因为我的反应相对比较慢，因此可以即时暂停、回溯的网课对我而言吸收效果会好很多。

个人认为，想要取得 4.0 以上的绩点，跟着苏老师的网课其实就够用了。相较于深挖一个知识点，对整本书形成全局性的理解，有自己的知识框架似乎更加重要。

### 2. 关于小测

毕老师的小测分似乎可以用 MOOC 补满，所以期末千万不要忘记补上慕课！（当然课程规则可能会有变化，以实际情况为准。）

一学期有两次小测，建议小测前 2 天可以把历年小测题刷一遍，了解题型并针对性地准备（突击？）一下。第一次小测在期中前，第二次在期末前。

也可以尝试将一部分期中、期末复习的任务提前迁移到小测前完成。虽然期中期末的考察方式和小测还是有差异的，不过提前过一遍知识总是好的～

### 3. 期中期末

期中不会有停课自习的时间，是一边推进新课，一边在周末安排考试的。期末会有约一周的空白自习时间，但相应地要准备的课程也会更多。

建议期中、期末至少提前 1—2 周把历年卷刷一遍。

我的历年卷使用方式是：例如有近十年的历年卷，我会将离得最远的 5 份作为知识点搜集和回忆的练习卷，遇到不会的题目就回溯课本去复习；次远的 3 份作为限时训练集，记录自己做题的时间和仍然有问题的知识点，进行第二次巩固；最后将近两年的 2 份历年卷作为考前测试集。

## 总结

因为我个人不是非常擅长数学，投入了较多的时间“硬”学，最后取得的成绩也是刚刚达到预期，经验方法仅供参考。
