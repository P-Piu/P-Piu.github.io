# 军训

<p class="course-meta">大一上（秋冬） · 2.0 学分</p>

军训是大一入学的第一门课程。个人觉得如果不是对绩点要求特别高，正常参训即可，也可以选择加入连部降低强度。

25 年军训时，因为我有转专业的规划，所以做了较多的工作：

**军训班长：** 管理十人左右的一个军训班，整体工作并不繁重，主要负责通知传达和通讯稿收集。

**合唱：** 是非常值得回忆的军训体验！

**哨兵：** 主动报名即可，比较枯燥，体力好的同学可以去一次体验一下。

**实体宣传稿件：** 个人认为比文字稿件更容易推送上去加分。

最后可能需要注意的就是一些基本要求：内务卫生尽量做好，千万千万不要偷偷带手机（被抓到就坏菜了）。另外，身体不舒服一定要及时提出，这个比其他事情都重要，不要硬撑。
