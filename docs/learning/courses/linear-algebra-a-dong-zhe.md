# 线性代数（甲） - 董浙

<p class="course-meta">大一上（秋冬） · 3.5 学分</p>

## 课程体验

我还蛮喜欢 dz 老师一根粉笔在黑板上写一节课的上课方式的，可以顺着老师的思路过一遍课本。当然有时候，尤其是后期、尤其是第四章开始，偶尔甚至总是会跟不上思路呢。

## 经验分享

### 1. 一遍不行，那就两遍

本人的学习方式非常简单粗暴（命苦）。前期听课还比较能跟上老师节奏，到了十月、十一月开始就逐渐听天书，但是我发现，在教室里的天书，当打开智云播放第二遍时，突然就入耳了很多。

所以我后期的线代学习方法就是：课上听一遍，不管听不听得懂，让大脑预加载；课后用智云或自己研读对应课本片段，并手写笔记，整理知识点对应的解题方法。

### 2. 做题

董老师不会布置很多课后作业。独立完成每周的课后作业（不会的先自己想，再求助 AI 啦），基本上也就覆盖了期中期末考察的填空题型。

我没有额外刷很多题，只是把不同题型对应的原理和方法进行了参悟和总结。

### 3. 关于小测

董老师的小测非常捞捞啊！一共两次，去了就有 4 分，答得好的 5 分。不过每次小测一个班都会分前后两波去测，经验规律就是：如果某次小测一个班题目比较简单，好像另外一个班就会比较难。

不过在宽松的小测分数机制下，大家尽力而为就可以啦～

### 4. 期中期末

改革为 AI 阅卷后，期中期末前面的填空题几乎送分，在认真总结覆盖的不同题型后，难度并不大，只是要知道怎么做题。当然新学期的难度我不做定论。

而大题则不然。我当时期末大题怒砍 0 分，都在每道题的第一步就写下雷霆错误。不过好在大题分数占比很少，只要认真拿下前面的填空，大题努力发挥一点，是可以取得理想的分数的！
