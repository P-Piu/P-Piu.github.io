# 《老友记》

初二升初三的暑假，我想精进英语，于是打开了这部经典美剧。那时每听几句台词，我就暂停下来记录一些口语表达，整整写满了一个笔记本——不过现在已经找不到了。因为听几句就要记录，还总是来回拖动进度条，光是第一集就看了好多遍。

高三毕业后的暑假，我决定复读。试读两周回家后，在正式开学前的休整阶段，我又打开了《老友记》，从第二季开始继续看。复读的一年里，我断断续续地看着；寒假终于看到了 Chandler 与 Monica 的求婚片段——尽管初中时就已经听过很多遍《Wonderful Tonight》。到了暑假，我终于看完最后一集，也第一次完整地走完了这十季。

无论高兴还是低落，我好像都可以随便点开其中一集，看他们欢乐、吵闹，又在彼此身边获得治愈。这部剧也像片头曲唱的那样，总是：“I’ll be there for you.”

我最喜欢的角色是 Chandler，从初中开始就很喜欢他。原因吗？钱钱的每一句台词都好像长在了我的笑点上。幽默之外，他对待朋友真诚又暖心，也勇敢地突破自己——不管是在亲密关系里，还是在事业上。

简直太完美了，我说。
