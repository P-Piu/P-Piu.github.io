# 年少的子弹正中眉心，是遗憾还是成长？

_2026 年 8 月 9 日_

最近看到一个辩题：“年少的子弹正中眉心，是一种遗憾还是成长？”

目前我只看了不到一半，因此这篇文章并不是对整场辩论的完整评价，只是记录我看到孔乙己这个例子之后产生的一些想法。

## 我最先想到的，是回响 { data-toc-label="最初的回响" }

“年少的子弹正中眉心”首先让我想到的是一种回响、应验或者 callback。

过去说过的一句话、作出的一个判断，甚至只是某个未经思考的选择，在许多年后以意想不到的方式返回，击中了现在的自己。它因此显得痛，也显得格外戏剧性。

但在最开始，我并没有立刻觉得这是“明白了什么”，或者“失去了什么”。

## 成为孔乙己，与意识到自己成为了孔乙己 { data-toc-label="成为与觉察" }

年少时，我们可能笑过孔乙己，把他当成一个与自己无关、可以被轻易分析的人物。多年后重读，却突然从他身上看见了自己。

我觉得在这个例子里，需要区分两件事：成为孔乙己，以及意识到自己成为了孔乙己。

遗憾的是，我没有成为年少时想象中的大人。也许我还会遗憾，为什么自己没有更早意识到这一点。但后者遗憾的是觉察来得太迟，而不是觉察本身。

成长则可能发生在子弹正中眉心的瞬间。因为我终于意识到，自己已经能够看见当年看不见的东西，也能理解当年无法理解的人。

## 遗憾是被照见的内容，成长是看见之后的变化 { data-toc-label="遗憾与成长" }

年少的子弹并没有制造“没有过上期待中的人生”这一遗憾。它只是让原本已经存在的人生落差，在某个瞬间突然显形。

因此，我更愿意把遗憾理解为子弹照见的内容，而把觉察、反思以及之后发生的改变理解为成长。

但仅仅意识到这一点，或许还不够。

如果这次顿悟只带来自嘲和痛苦，没有产生新的理解，也没有改变此后对待自己和他人的方式，那么它未必能够被称为成长。

真正的成长可能发生在更后面：我意识到年少的自己受阅历和认知限制，也意识到现在的自己仍然可能在向未来射出新的子弹。于是我开始更谨慎地作出判断，也愿意重新理解那些曾经被我轻易评价的人。

## 成长不能替遗憾开脱 { data-toc-label="成长与责任" }

如果年少时的言行确实伤害过别人，那么遗憾指向的是过去的伤害，以及那些已经无法挽回的损失。

正中眉心之后，对错误的理解、承担和改正可以成为成长，但成长不能抵消已经造成的伤害，也不能把别人的伤痛美化成自己的成长素材。

当真实的损失已经无法挽回时，如果把整件事主要命名为“成长”，可能会过度关注后来的人得到了什么，却淡化了别人永久失去了什么。

所以，我们或许还需要区分：这一刻对“我”产生了怎样的作用，以及应该如何评价整件事情。

## 暂时的答案 { data-toc-label="暂时的答案" }

遗憾的是子弹照见的人生境遇与无法挽回的损失；成长发生在我终于看见、反思，并决定不再射出同样子弹的时刻。

不过，这只是我看了部分辩论之后的暂时判断。辩题中的“年少的子弹”“正中眉心”和“这件事”分别指向哪一段过程，都会直接改变问题的答案。

也许等我看完整场比赛之后，还会重新回来修改现在的想法。
