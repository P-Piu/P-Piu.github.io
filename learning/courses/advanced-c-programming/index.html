    C程序设计基础及实验（C尖） - 张引¶

    大一上（秋冬） · 4.0 学分

    一开始在听说 C 尖极高的挂科率时选择这门课，我是有点没底的（因为自己专业要求的是 3.0 学分的 C 小）。但是学到后期，尤其是高强度准备实验考和期末考阶段，我发现 C 语言本身还是挺有意思的，像数组、指针、链表等等。

    个人的经验¶

    1. 合理利用课本¶

    虽然啃书是一件比较累人的事儿，但是在课后和期末总复习时，书本是很不错的资源。

    我会在每周课后利用课本复习（或者说补习，因为上课容易上着上走神咳咳……）当周的知识，期末也是挑了一些还没有仔细看或已经遗忘的课本部分重点阅读。

    有不太理解的地方搭配 AI 梳理，再用自己的话说一遍，记录在电脑文档中，效果还是很不错的。

    2. B站资源¶

    由于我没有编程基础，一开始学 C 程这门课还是有些畏难的。为了更好地入门，我选择了翁恺老师的视频课程。

    每集时长都很短，适合在碎片时间补习（也可以连刷哈哈哈）。

    前期我会比较依赖视频课程，到了学期后半逐渐掌握了 C 程学法，也就更多地投向课本和课堂啦（张引老师讲得还是非常详细的，我很喜欢这位老师～）。

    3. 考前复习资源¶

    当时我没有订学解的资料。在自己搜集资料的时候，我发现 C 尖的历年卷资源比较少，考前也就刷了 13、14 两年的历年卷，个人感觉够用了：一份用来熟悉题型，便于针对复习；另一份用于自测。

    C 尖分为实验考和理论考，秋冬学期的实验和理论是分开的。

    关于实验考¶

    考前由于我本人比较焦虑（毕竟如果两题没一题完整答对，补考再不过就挂了呀！！），所以实验考前一周花了大概 20 小时有余来刷 PTA 的程序题和复习整理。

    其实这也相当于把期末理论考复习做了一个提前，我觉得是划算的。

    最后实验考考察得还是比较基础的。给大家的建议就是不要太紧张，看到题目先冷静，有思路了再开始写代码，没问题的！

    关于理论考¶

    理论考难度还是比较大的，选择题和填空题个人感觉简直处处挖坑。

    非常推荐考前记忆一遍运算符优先级表（毕竟选择填空真的会考这种细碎的语法），还有像宏定义替换、递归这样的考点。

    4. 总结¶

    C 程是我认为体验感挺不错的课程。并且后续嵌入式相关的代码也真是要好好学好 C 语言啊，不然就会变成旁观 AI 的猿人……比如我最近就是这样。
